Новые hero/shell/CSS/motion, раскрывающиеся категории, маршрут арсенала из пистолета/винтовки/ножа. Сохранены избранное, сравнение, фильтры/поиск, Steam, баланс, Apple, конвертер, FAQ.

- Главная 320/390/768/1440: scrollWidth = clientWidth (305/375/753/1425); переполнения нет. Дополнительно визуально исследован desktop 960.
- Каталог, полная карточка Printstream, корзина и кабинет 320/390: scrollWidth = clientWidth (305/375). Мобильное меню закрывается при переходе.
- Glock Gamma Doppler: quick view → добавить → уведомление внутри dialog:modal (desktop bottom 976 при высоте 1000) → ссылка в корзину → окно закрыто → предмет присутствует.
- Повторное открытие того же предмета показывает ссылку «Перейти в корзину». Повторный переход не добавляет дубль.
- Конструктор: бюджет 1 ₽ показывает превышение и отключает добавление; 30000 ₽ разрешает. В корзину добавлены Desert Eagle, AUG и Охотничий нож. Независимые переключения винтовки и ножа проверены; смена винтовки обновляет состав/цену.
- После reload корзины дождались гидратации: все 5 проверочных предметов, включая Printstream, сохранены. Тестовые предметы удалены через UI; пустая корзина показывает работающую ссылку в каталог.
- Printstream: поиск даёт 1 результат; избранное + saved фильтр дают 1. Диапазон 100 → 1 показывает ошибку. Полная страница → добавление → рабочая ссылка → предмет в корзине. Избранное очищено через UI.
- Apple: США + подтверждение → Турция сбрасывает подтверждение, блокирует запрос цены, сводка 100 TRY. Новый запрос после подтверждения сообщает недоступность; заказ не создаётся.
- Кабинет: невалидный trade URL отклоняется; операции/покупки пусты. Escape в выходе сохраняет кабинет и возвращает фокус на «Выйти». Подтверждённый выход работает.
- Quick view: найден и исправлен случай сохранения окна при Back. Повторная проверка: route изменён, dialog отсутствует. Escape возвращает фокус на исходный quick-view button.
- Native dialog дополнен явным wrap фокуса; 9 последовательных Tab остаются внутри окна. До исправления наблюдался выход фокуса в browser chrome.
- Уведомление использует постоянно смонтированный live region; экранная программа озвучивания отдельно не запускалась.
- Загруженные товарные изображения имеют naturalWidth > 0. На проверенных экранах не обнаружено runtime errors.
- CSS reduced-motion отключает transitions, blur reveal, smooth scroll, parallax и декоративные анимации; имитация системной настройки не проводилась.

## Ограничения
Не подключены реальные платежи, Steam OpenID, live vendor/выдача и поставщик Apple; отсутствуют контракты/доступы и юридические сведения. Публичная версия — интерфейс с локальным состоянием, не коммерческий запуск. На GitHub Pages серверная проверка Steam также сообщает недоступность. Нельзя трактовать каталог как текущие остатки.

## Общая анимация появления
Покрытие проверено в DOM: на главной отсутствуют заголовки, кнопки, поля, тексты p и изображения вне motion-групп; 68/68 карточек каталога имеют calm. Проверены повторное появление результатов при очистке поиска, quick view, add → notice внутри dialog → cart → Printstream (тестовый предмет удалён), FAQ-ответ waiting→running, анимации футера, кабинет. На 390 px нет переполнения; размеры/выравнивание заголовков сохранены. Enter открывает hero quick view; Escape возвращает фокус на видимую карточку. 24 tests, typecheck, lint и static build 74 страниц прошли. Системная reduced-motion эмуляция не запускалась; проверена ветка matchMedia и отмена анимаций в коде.

При финальной проверке найден и исправлен hydration mismatch каталога: PageMotion больше не добавляет служебные DOM-атрибуты до гидратации Suspense. Состояние хранится только в Map, Web Animations API не изменяет React-разметку. После исправления свежий прямой вход в каталог, поиск и переход главная → каталог не дали ошибок браузера; typecheck/lint и static build повторены.
