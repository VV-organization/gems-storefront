# Каталог нескольких игр — Gems

Дата внедрения: 12 октября 2026. Источник: https://shop-skin.com/catalog.

## Данные и полнота

Выгружен полный публичный ассортимент напрямую через GET API источника 12 октября 2026. Первоначально при недоступном API использовался снимок из соседнего проекта Chips; после восстановления API он полностью заменён свежими данными. Оформление, конфигурация публикации и секреты другого проекта не переносились.

Сохранены все строки доступного снимка, без ограничения по цене или типу. Категории и их названия совпадают с исходными данными.

Количество уникальных ID по каждой игре совпало с `totalCount` API в конце выгрузки. Для CS2 дополнительно проверено количество в каждой из 18 категорий; дубликатов нет. В снимках сохранены `capturedAt`, `totalCount` и `sourceReportedCount`. Первоначальное расхождение в 12 позициях старого снимка устранено новой полной выгрузкой.

948 позиций CS2 имеют пустой imageUrl в источнике. Они не исключены: отображается «Изображение недоступно». Для сетевых ошибок изображений применяется тот же fallback. Остальные изображения загружаются с исходных публичных Steam URL. Это датированный снимок, не подтверждение текущего наличия, цены или возможности выдачи.

## Выбор и оформление

Сначала выбирается игра, затем её категория. Смена игры сбрасывает категорию и специфичные параметры CS2, сохраняет поиск, цену и сортировку. Категории доступны в боковой панели с поиском по названию; на телефоне панель раскрывается кнопкой «Фильтры».

Поиск по имени/оружию/marketHashName; четыре сортировки источника: цена по возрастанию/убыванию, имя А–Я/Я–А. Сохранены дополнительные фильтры Gems: цена в Gems, избранное; состояние и StatTrak только для CS2. Выдача по 24, кнопка «Показать ещё», счётчик, пустое состояние и повтор при ошибке. Состояние выбора сохраняется в URL.

Оформление продолжает текущий Gems: локальный Commissioner, зелёный фон, золотой активный выбор, тонкие разделители, общие строки карточек, спокойные анимации каталога. Дизайн соседнего проекта не использован. Старые 68 товаров главной и их ссылки сохранены.

## Деньги и страницы

Цены источника сохранены в минимальных единицах Creeps. Пересчёт: `rubMinor = (quoteMinor × 17 + 5) / 10` с целочисленным делением и округлением half-up; `gemsMinor = rubMinor × 2`. Пример: 5,04 Creeps → 8,57 ₽ → 17,14 Gems. Рублёвый эквивалент не изменяется повторным округлением.

Курс 1 Creeps = 1,7 ₽ подтверждён публичной конфигурацией самого источника (`projectConfig.rublesPerCreep`).

Парсер цены каталога поддерживает дорогие предметы. Ограничение ввода для пополнений осталось прежним. Локальная корзина хранит только выбранные импортированные товары для показа после reload; эти данные не используются как доверенная платёжная котировка. Реального провайдера покупки нет.

Полный индекс загружается только для выбранной игры, описания — по небольшим частям по запросу. Главная не получает все 34 тысячи товаров. Новые прямые ссылки `/item?game=…&id=…` работают в статическом экспорте Pages с `/gems-storefront`. Старые `/catalog/<id>` сохранены.

## Обновление

`python3 scripts/refresh-reference-catalog.py [cs2 rust tf2]` — только публичные GET-запросы. Скрипт проверяет курсоры, категории, игру и количество. Количество каждой категории и общий итог сверяются с API. При расхождении существующий индекс не заменяется. При недоступном API требуется повторный запуск после восстановления источника; автоматическое обновление не настроено.

- 30 unit-тестов, включая все строки снимка, категории, наличие описаний, цены, большие суммы, сортировки и повреждённое локальное хранилище.

- В браузере: Rust 5 019; поиск hoodie 164; Weapon 1 746; TF2 Rocket Launcher 17; пагинация 24 → 48; смена игры сбрасывает категорию.
- Избранное и корзина после reload, дорогой Rust + TF2 в одной корзине, существующий товар становится ссылкой «Перейти в корзину».
- Быстрый просмотр, уведомление внутри dialog, Escape и возврат фокуса, мобильная корзина и отсутствие горизонтального переполнения на 390px.
- Статический экспорт: прямой вход и reload `/item`, загрузка описаний, корзина, ошибка загрузки каталога → повтор, товар без картинки сохраняется в корзине.
