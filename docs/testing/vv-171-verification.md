## Платежи: установленные ограничения

Проверена среда основного процесса API, а не отдельного `docker exec`: entrypoint создаёт secret files и меняет environment. Значения секретов не выводились.

- `ARCO_PAY_PROVIDER_MODE=disabled`; отсутствуют API key file, bearer token file, shop ID, public key file проверки callback.
- SIH catalog, SIH Steam refill и SMTP secret files доступны процессу.
- Commerce feature flags выключены. Их включение само по себе не настроит merchant и не докажет оплату.
- Пользователю задан вопрос о защищённом расположении боевой конфигурации именно магазина Gems. Секреты соседних проектов не переносились.
- Для реальной приёмки также нужны согласованные получатель Steam/trade token и сумма. Эти acceptance-параметры не являются дефектами пользовательской формы.

Локальные интеграционные тесты проверяют quote → session → hosted checkout, привязку суммы/магазина/операции, подпись callback, повтор callback и reconciliation, однократное зачисление и отдельный Steam flow без изменения Gems wallet. Они используют тестовые провайдеры и не доказывают боевую оплату.

## Проверка на production и найденное узкое место

Релиз `3833706` прошёл оба CI и deploy. В существующей вкладке Chrome вручную подтверждены Steam-only диалог, нормальное поле почты Steam и чёрные стрелки конвертера. Новые окна и вкладки не создавались.

Первый публичный запрос вариантов оружия после деплоя превысил 15 секунд. План PostgreSQL показал около 34 тысяч обращений к полным строкам каталога и более 30 тысяч прочитанных блоков для выборки из 60 предметов. Это не было воспроизведено маленькой fixture-БД; проверка production не была объявлена завершённой.

Добавлены materialized selection ID перед чтением полных карточек и два покрывающих индекса (миграция 0045). В production индексы построены CONCURRENTLY, оба подтверждены `indisvalid=true`; незавершённый индекс первой попытки удалён. Ожидались штатные транзакции синхронизации, пользовательские данные и рабочие процессы не останавливались. Новый запрос прошёл backend verify (255 unit) и полный integration (167 passed, 1 внешняя SIH acceptance skipped). После обновления статистики план оружия использует целевой индекс и измерен в 6 мс; публичные замеры после публикации приведены ниже.

### Решения по результатам ревью

- Подбор бюджета показывает количество отобранных предметов, а не выдуманный total каталога.
- Номенклатура оружия независима от SSR и наличия: доступность проверяет preview. При отсутствии предложений показывается пустое состояние.
- Ошибка повтора сохраняет успешную пару того же оружия; ответ предыдущего оружия не заменяет текущий выбор.
- Проверки таймаута и гонки ответов, отмеченные ревью как minor, включены в обязательную регрессию по исходному плану.
- Тестовые провайдеры, redirect и успешный deploy не считаются доказательством настоящего платежа, зачисления или выдачи.

**Остаток по пункту 10:** настроить через защищённую конфигурацию магазина Gems ArcoPay API key, bearer token, shop ID и public key callback, затем провести отдельную реальную приёмку с согласованными суммой и получателем. До этого VV-171 целиком не закрыта. Остальные обнаруженные интерфейсные дефекты исправлены и проверены в описанных границах.
